# NOBARTONTONANNEW
NobarTontonan adalah web streaming film dibangun dengan Next.js, TypeScript, Tailwind CSS, dan backend Express + Redis. Menggunakan TMDB API untuk metadata dan Embed API untuk pemutar video. Proyek ini dibuat murni untuk tujuan portofolio dan edukasi UI/UX modern, tanpa meng-host file video berhak cipta sendiri.
